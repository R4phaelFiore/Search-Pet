# 🐾 SearchPet

**Plataforma web para incentivo à adoção responsável de animais.**

O SearchPet é um sistema desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Desenvolvimento de Sistemas da ETEC Centro Paula Souza – São José dos Campos/SP.

O projeto tem como objetivo conectar pessoas interessadas em adotar animais a pessoas, ONGs e abrigos que desejam encontrar um novo lar para seus pets, promovendo a adoção responsável e contribuindo para a redução do abandono animal.

## ❤️ Objetivo social

Contribuir para a conscientização sobre a adoção responsável, proporcionando maior visibilidade aos animais que procuram um novo lar.
